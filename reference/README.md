# Reference snapshot

This directory preserves data and results produced by the pre-migration
`physkit` project. Files here are read-only reference artifacts, not default
output destinations for current examples.

The metadata under `data/meta/` intentionally retains historical
`physkit.*` tool identifiers. Those values are provenance records describing
the software names used when the snapshot was created and must not be rewritten
to `precision_physkit.*`.
